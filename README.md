# 🎮 Tetris - Classic Arcade Game

A fully functional Tetris game built with HTML5 Canvas and JavaScript.

## 🕹️ Play Online

**[Play Tetris Now!](https://stasik5.github.io/tetris/)**

## ✨ Features

- **Classic Tetris Gameplay**: All 7 tetromino pieces (I, O, T, S, Z, J, L)
- **Smooth Controls**: Responsive keyboard controls
- **Ghost Piece**: Preview where your piece will land
- **Next Piece Preview**: See what's coming next
- **Scoring System**: Points for clearing lines and hard drops
- **Level Progression**: Game speeds up as you clear more lines
- **Pause Function**: Take a break anytime
- **Beautiful Design**: Modern gradient UI with 3D block effects
- **Game Over Screen**: Final score display with replay option

## 🎮 Controls

| Key | Action |
|-----|--------|
| ← → | Move left/right |
| ↑ | Rotate piece |
| ↓ | Soft drop (faster fall) |
| Space | Hard drop (instant drop) |
| P | Pause/Resume |

## 📊 Scoring

- **Soft drop**: 1 point per cell
- **Hard drop**: 2 points per cell
- **Line clears**:
  - 1 line: 100 × level
  - 2 lines: 300 × level
  - 3 lines: 500 × level
  - 4 lines (Tetris!): 800 × level

## 🏗️ Tech Stack

- **HTML5 Canvas**: For game rendering
- **Vanilla JavaScript**: Pure JS, no frameworks
- **CSS3**: Modern styling with gradients and effects

## 🎯 How to Play

1. Use arrow keys to move and rotate pieces
2. Complete horizontal lines to clear them and score points
3. Clear 4 lines at once for a "Tetris" bonus!
4. The game speeds up every 10 lines cleared
5. Game over when pieces stack to the top
